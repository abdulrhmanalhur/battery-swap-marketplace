# بطاقة تفعيل قراءة MongoDB — بانتظار الموافقة

## النطاق والجهات التي ستطّلع على البيانات

أقترح تمكين Codex لدى OpenAI وClaude لدى Anthropic، من جلسات المالك المصادق عليها فقط، من قراءة حقول الأعمال المسموحة في قاعدة test على Cluster0، بمشروع Battery swap رقم69cd58b657e3ebb03722b5ba. عند استدعاء الأدوات ستصل النتائج المصفّاة إلى جلسة Codex أوClaude المستخدمة، وليست معلومات تبقى داخل السيرفر وحده. البيانات المالية والشخصية المذكورة أدناه جزء من نطاق الموافقة.

توجد سياسة لكل المجموعات الـ57 المتحققة من Atlas، مستندة إلى57نموذجًا عامًا بالمستودع Battery-Swap-V2 عند commit a71824819f80cd6ce97c74e216f8b11a1a0f3fb1. تفاصيل الحقول واستبعاداتها في read-policy.json وPOLICY-EVIDENCE.json. لا قراءة لمستندات إنتاج أثناء التحضير.

## ما سيظهر

- المنتجات والسيارات والموردون: أسماء وتسميات مقيدة، أسعار وتكاليف وكميات ومخزون وتوزيع الفنيين وحركاته وتواريخ العمليات.
- الفواتير والمبيعات والضمان والعربون: أرقام الفواتير، البنود، الكميات، التكلفة، الإجمالي والخصم والرسوم والربح، أجزاء الدفع، وحالات المطابقة والمراجعة وتوقيتها.
- المال والموظفون: أرصدة الكاش والائتمان والحسابات الخارجية، فروق الحركات، البونص وقواعده، مبالغ الرواتب ودوريتها وحالة دفعها، ومرجع الموظف المستعار. هذه بيانات أعمال وموظفين مالية حساسة ستظهر للأداة المستدعاة.
- بيانات شخصية محدودة: أسماء العرض وأسماء الشركات والموردين وأطراف الحوالات حيث توجد حقول صريحة بالنموذج. الهواتف المعتمدة تظهر آخر4أرقام ومرجعًا ثابتًا فقط، والبريد يظهر نطاقه ومرجعًا ثابتًا؛ معرّفات المستخدمين النصية تظهر كمراجع مجزأة. المراجع للتطابق بين العمليات، وليست إخفاء هوية قويًا؛ يمكن تخمين أرقام الهواتف منخفضة الاحتمالات. بعض حقول الهاتف الموسومة select:false مستبعدة تمامًا.
- الإسناد التسويقي: القنوات والحالات والأوقات والتسميات المعتمدة ومراجع الارتباط المستعارة، دون payload أوsnapshot أوبيانات المصادقة.
- الرسائل والمزامنة: أرقام الرسائل التقنية وتواريخها ونوعها ومعرّفات/تسميات المرشحات وحالات وأعداد المزامنة فقط؛ لا نص الرسالة أوOTP.

## الاستثناءات وحدود القراءة

تُحجب كلمات المرور، أكواد دخول المديرين، رموز ومفاتيح البوتات وحقول Telegram، بيانات الاعتماد والتوقيع والمصادقة، أكواد القسائم القابلة للاسترداد، أرقام الحسابات البنكية الكاملة، وروابط/صور/ملفات الإيصالات. تُحجب body/message/note/reason/error/description والنصوص الحرة، والـMixed والأنواع غير المحسومة وحقول select:false؛ ولا تُعرض قيم BSON غير المعتمدة أو القيم المشبوهة حتى داخل حقل تسمية مسموح.

تغطية المجموعات لا تعني عرض محتوى كل حقل: sitecontents تتيح المعرّف والتواريخ والعدد فقط لأن data من نوعMixed؛ attribution_customer_locks تتيح المعرّف والمراجعة العددية؛ madareceiptminutelocks تتيح المعرّف المستعار وversion. بقية الحقول المحجوبة لا تُفتح ضمن هذه الموافقة.

الأدوات find/count فقط. المرشحات الرقمية والتواريخ والمنطقية متاحة؛ enum وObjectId يقبلان مساواة/قائمة قيم فقط. لا ترشيح بالنصوص أو الهواتف أو البريد أو المراجع المستعارة أو الحقول الحرة أو عناصر المصفوفات؛ لمنع استنتاج محتوى محجوب عبرcount. الحد100مستند و1MiB للنتيجة و3ثوانٍ لتنفيذ الاستعلام، وعمليتا DB متزامنتان. pool=2 لكل خادم مع مقابس مراقبة إضافية؛ ليس حدًا إجماليًا لاتصالين. الكتابة والحذف والمقترحات والتصدير والأوامر الإدارية مغلقة.

## الوصول والمصادقة المقترحان

تطبيق GitHub OAuth جديد مستقل باسم BatterySwap MongoDB Read، يقبل المالك abdulrhmanalhur بمعرّف108840765 فقط، بعد التحقق من GitHub العام. لا صلاحيات repo/email إضافية، ونطاق GitHub فارغ؛ النطاق المحلي mongodb:read. لا إعادة استخدام لأسرار Atlas Monitor.

## التغييرات التي تحتاج الموافقة

- إنشاء تطبيق GitHub OAuth وحساب MongoDB المحددين، وإدخال بياناتهما بواسطة المالك.
- نشر المصدر المراجع عبر مسار Git/PR والمصدر المعتمد إلى /opt/batteryswap-mongo-read، وتسجيل المصدر قبل النشر. لا تشمل الموافقة دمجPR1 الخاص بـAtlas Monitor.
- تثبيت وبدء /etc/systemd/system/batteryswap-mongo-read.service فقط، بمستخدمDynamicUser وتخزين خاص وLoadCredential، والاستماع127.0.0.1:8018 بعد فحص توفره.
- إضافة /etc/nginx/conf.d/batteryswap-mongo-read-limits.conf و/etc/nginx/snippets/batteryswap-mongo-read.conf، وinclude محدود داخل TLS virtual host الحالي للبوابة. تُراجع رقعة أحدث إعداد تحت القفل بعد تحديد اسم ملفه الفعلي؛ لا افتراض لاسم الملف ولا استبدال للإعداد الكامل.
- التوجيه محصور بمساراتMongoDB والمصادقة وmetadata أعلاه، مع تعطيل تسجيل رموز OAuth وحدود طلبات. لا تغيير لمساراتOAuth العامة أو الموصلات الأخرى أو خدمةMongoDB القديمة.
- فحصLinux imports وsystemd-analyze verify وnginx -t ثم إعادة تحميلNginx بسلاسة وفحص الموصلات المجاورة. الخطر متوسط بسبب البوابة المشتركة.

لا تغيير لخطةAtlas أوTLS أومستخدمي التطبيق الحاليين أوالشبكة ضمن النطاق. إذا منع السماح الشبكي الحالي الاتصال، نتوقف لعرض تغييرIPمحدد بموافقة منفصلة.

## خطوة المالك الخاصة والتحقق والتراجع

بعد الموافقة فقط، يدخل المالك القيم الثلاث عبرpromptمخفي في طرفيةTTYآمنة باستخدام deploy/store-private-value.py: URI الحساب الجديد بـmongodb+srv و/test، ومعرّف تطبيقGitHub وسره. لا يرسلها في المحادثة أوصور أووسيط أمر أوGit. تحفظ في /etc/batteryswap-mongo-read بصلاحيةroot0700 والملفات mongodb-uri وgithub-client-id وgithub-client-secret بصلاحيةroot0600. الأداة ترفض بيئة الإدخال الظاهر، ولا تقرأ أوتستبدل الموجود. يفحص الوكيل وجود الملفات وأذوناتها ونجاح المصادقة فقط دون قيمها.

بعد موافقة التنفيذ: اختبار401بلا تسجيل، ودخول المالك، ورفض الرموز/الموارد الأخرى، وقراءة محدودة مصفّاة وغياب أدوات الكتابة. لا اختبار تحديث أوحذف حقيقي. تشغيلLinux وNginx/systemd وRBAC وتسجيل دخول العملاء فعليًا لم تُختبر بعد؛53اختبارًا محليًا نجحت دونMongoDBشبكي، و72عجلةLinux متحقق من بصماتها وتبعياتها.

التراجع: تعطيل المسار/إدخال العميل الجديد وإيقاف الخدمة الجديدة فقط واسترجاع الإضافات المطابقة دون سحق إعداد أحدث. لا حذف بيانات أوتنظيف تلقائي للأسرار. القراءة لا تحتاج مضيف كتابة مستقل؛ الكتابة تبقى مغلقة.

لم يُنشأ حساب أوتطبيق أوسر، ولم يُنشر أويدمج أوتتغير إعدادات إنتاج. المطلوب الآن موافقة صريحة على نطاق البيانات والجهات المستفيدة وتغييرات الوصول المذكورة، ثم إتمام خطوة المالك الخاصة وفحوص التفعيل.
